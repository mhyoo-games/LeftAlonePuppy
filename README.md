# 홀로 남은 강아지 (Left Alone Puppy)

이삿날, 건초 더미에서 깜빡 잠든 아기 강아지 **콩이**. 눈을 떠 보니 가족은 이미 도시로 떠나 버렸다.
콩이는 하나의 냄새를 따라 농장에서 도시까지 여덟 곳을 지나는 길을 떠난다.

브라우저에서 바로 하는 횡스크롤 모험 게임입니다. 키보드와 휴대폰 터치 둘 다 됩니다.

## 하는 법

| 키 | 하는 일 |
| --- | --- |
| ← → | 걷기 |
| Z / 스페이스 | 점프 (길게 누르면 높이) |
| X | 멍! — 앞에 있는 적을 놀라게 해 잠깐 멈춘다 |
| ↓ + Z | 판자 아래로 내려가기 |
| Esc | 쉬기 |

- 적은 위에서 밟으면 물리친다. 가시 고슴도치는 먼저 짖어서 몸을 말게 한 뒤에 밟는다.
- 물그릇은 쉼터. 마시면 기운이 나고 거기서 다시 시작한다.
- 스테이지마다 숨겨진 **하나의 추억**이 하나씩 있다. 엔딩에서 함께 찾은 추억을 모아 볼 수 있다.
- 보스는 공격한 뒤 어지러워할 때 밟는다. 박쥐는 짖어서 떨어뜨린다.

## 만든 방법

- TypeScript + Canvas 2D, 320×180 도트 화면을 키워서 보여 준다. 외부 게임 엔진 없음.
- 맵은 짧은 조각을 이어 붙여 만들고, 테스트가 "시작에서 보스까지 갈 수 있는지·추억과 뼈다귀에 닿을 수 있는지"를 길 찾기로 확인한다.
- 간단한 봇이 보스 여덟 마리를 모두 이기는지도 테스트로 확인한다.
- 콩이·적·보스·하나는 코드로 그린 도트, 배경 소품은 Kenney Tiny Farm. 배경음악·효과음은 Web Audio로 합성한 새 곡.

```
npm install
npm test          # 규칙 테스트
npm run build     # dist/
```
